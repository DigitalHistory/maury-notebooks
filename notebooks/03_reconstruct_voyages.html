Step 3: Reconstructing Voyages from Observations

Reconstructing Voyages from Observations

The ICOADS data contains individual ship observations—single points in time and space. But for analysis, we want voyages: connected sequences of observations representing a ship’s journey. This notebook explains Ben Schmidt’s algorithm for reconstructing voyages from raw observations.

You’ll learn:

  1. Why voyage reconstruction is hard (the name collision problem)
  2. Schmidt’s four criteria for grouping observations
  3. The haversine formula for calculating distances at sea
  4. How to detect and handle name collisions
  5. Creating voyage summaries with aggregated features

The Challenge

Each ICOADS observation is independent—just a ship ID, position, and timestamp. To reconstruct voyages, we need to connect observations from the same ship in sequence. But there are complications:

Problem 1: No Voyage IDs. Each observation stands alone with no explicit link to consecutive positions. We must infer voyages from patterns in the data.

Problem 2: Multiple Voyages per Ship. Ships made many voyages over years, so the same ship ID appears hundreds of times. We need to separate these into distinct journeys.

Problem 3: Name Collisions (The Hard Part!). Ship IDs are truncated to 9 characters, so different ships can share the same ID. “ELIZABETH” could refer to five different vessels. When we see simultaneous observations at distant locations, we know they must be different ships.

Schmidt’s Four-Criterion Algorithm

Ben Schmidt developed a robust algorithm that uses four criteria to decide whether two consecutive observations belong to the same voyage:

  1. Same Ship Name. The observations must have the same ID field. This groups observations by vessel identity.

  2. Temporal Continuity (< 30 days). Consecutive observations must be within 30 days of each other. Gaps longer than this indicate separate voyages by the same ship.

  3. Spatial Continuity (< 1000 km). Consecutive observations must be within 1000 km of each other. This prevents impossible jumps caused by data errors or long port stays.

  4. No Simultaneous Observations. If the same ship ID appears in two distant locations on the same day, those observations must come from different physical ships. This criterion handles the name collision problem.

Let’s implement the first two criteria. We’ll work with a small sample dataset first to understand the algorithm, then apply it to the full ICOADS data. The sample below simulates two ships (LOUISVIL and MARYSANN) with observations spanning multiple months.

Criterion 3: Spatial Continuity

To apply the spatial continuity criterion, we need to calculate distances between consecutive observations. Since positions are on the surface of a sphere (the Earth), we can’t simply use the Pythagorean theorem. Instead, we use the haversine formula:

def haversine_km(lat1, lon1, lat2, lon2):
    """
    Calculate great-circle distance between two points.

    The haversine formula accounts for Earth's curvature.
    Inputs are in decimal degrees; output is in kilometers.
    """
    R = 6371.0  # Earth's radius in kilometers

    # Convert to radians
    lat1_rad = np.radians(lat1)
    lat2_rad = np.radians(lat2)
    dlat = np.radians(lat2 - lat1)
    dlon = np.radians(lon2 - lon1)

    # Haversine formula
    a = np.sin(dlat / 2)**2 + np.cos(lat1_rad) * np.cos(lat2_rad) * np.sin(dlon / 2)**2
    c = 2 * np.arctan2(np.sqrt(a), np.sqrt(1 - a))

    return R * c

## Why Not Just Use Pythagorean Distance?
On a flat surface, distance = √((x₂-x₁)² + (y₂-y₁)²). But Earth is a sphere!
At the equator, 1° of longitude ≈ 111 km, but near the poles it approaches 0 km.
The haversine formula accounts for this curvature, giving accurate distances
regardless of latitude.
:::

def calc_distance_to_prev(group):
    """Calculate distance from each observation to the previous one."""
    lats = group['LAT'].values
    lons = group['LON'].values
    distances = [np.nan]  # First observation has no previous

    for i in range(1, len(lats)):
        dist = haversine_km(lats[i-1], lons[i-1], lats[i], lons[i])
        distances.append(dist)

    return pd.Series(distances, index=group.index)

Criterion 4: Detecting Name Collisions

The trickiest part is handling name collisions—when different physical ships share the same truncated ID. Schmidt’s insight: if the same ID appears in two distant locations on the same day, they must be different ships.

def find_simultaneous_conflicts(df, distance_threshold=500):
    """
    Find days where the same ship ID appears at distant locations.

    This indicates multiple physical ships sharing a truncated name.
    Returns a set of (ID, date) tuples with conflicts.
    """
    conflicts = set()

    # Create date key for grouping
    df = df.copy()
    df['_date_key'] = df['Date'].dt.strftime('%Y-%m-%d')

    for (ship_id, date_key), group in df.groupby(['ID', '_date_key']):
        if len(group) < 2:
            continue

        # Check if any pair of observations is too far apart
        lats = group['LAT'].values
        lons = group['LON'].values

        for i in range(len(lats)):
            for j in range(i + 1, len(lats)):
                dist = haversine_km(lats[i], lons[i], lats[j], lons[j])
                if dist > distance_threshold:
                    conflicts.add((ship_id, date_key))
                    break

    return conflicts

Schmidt’s Key Insight

The 9-character ID truncation means “ELIZABET” could be “Elizabeth”, “Elizabeth Ann”, or “Elizabeth Mary”—completely different ships. But physics helps us: no ship can be in the North Atlantic and South Atlantic on the same day. When we detect impossible simultaneity, we know we’re looking at different vessels sharing a truncated name.

The Complete Algorithm

Performance Note

The naive conflict detection below checks every pair of same-day observations—an O(n²) operation. For 1.3 million records, this could be slow. The production script in scripts/reconstruct_voyages.py uses optimizations like early termination and vectorized operations. For learning purposes, the simple version here is clearer.

Putting it all together:

def reconstruct_voyages(df, max_days=30, max_km=1000, verbose=True):
    """
    Reconstruct voyages using Schmidt's four-criterion algorithm.

    Parameters:
        df: DataFrame with YR, MO, DY, HR, LAT, LON, ID columns
        max_days: Maximum days between consecutive observations
        max_km: Maximum kilometers between consecutive observations
        verbose: Print progress information

    Returns:
        DataFrame with added 'voyage_id' column
    """
    if verbose:
        print(f"Input: {len(df):,} observations, {df['ID'].nunique():,} ship IDs")

    # Create datetime
    df = df.copy()
    df['_yr'] = pd.to_numeric(df['YR'], errors='coerce').fillna(1800).astype(int)
    df['_mo'] = pd.to_numeric(df['MO'], errors='coerce').fillna(1).astype(int).clip(1, 12)
    df['_dy'] = pd.to_numeric(df['DY'], errors='coerce').fillna(1).astype(int).clip(1, 28)

    date_str = (df['_yr'].astype(str) + '-' +
                df['_mo'].astype(str).str.zfill(2) + '-' +
                df['_dy'].astype(str).str.zfill(2))
    df['_datetime'] = pd.to_datetime(date_str, errors='coerce')
    df = df.dropna(subset=['_datetime', 'LAT', 'LON', 'ID'])

    # Sort by ship and time
    df = df.sort_values(['ID', '_datetime']).reset_index(drop=True)

    # Step 1: Find name collisions (criterion 4)
    if verbose:
        print("Detecting name collisions...")
    conflicts = find_simultaneous_conflicts(df)
    if verbose:
        print(f"  Found {len(conflicts)} conflict days")

    # Step 2: Assign voyage IDs
    if verbose:
        print("Assigning voyage IDs...")

    voyage_ids = []
    voyage_counter = 0
    current_voyage = None

    prev_ship = None
    prev_date = None
    prev_lat = None
    prev_lon = None

    for idx, row in df.iterrows():
        ship = row['ID']
        date = row['_datetime']
        lat = row['LAT']
        lon = row['LON']

        start_new_voyage = False

        # Check criterion 1: Same ship
        if ship != prev_ship:
            start_new_voyage = True
        elif prev_date is not None:
            # Check criterion 2: Time gap
            days_gap = (date - prev_date).days
            if days_gap > max_days:
                start_new_voyage = True
            else:
                # Check criterion 3: Distance
                dist = haversine_km(prev_lat, prev_lon, lat, lon)
                if dist > max_km:
                    start_new_voyage = True

        # Check criterion 4: Conflict day for this ship
        date_key = date.strftime('%Y-%m-%d')
        if (ship, date_key) in conflicts:
            # On conflict days, each observation starts a new voyage
            # (simplified handling)
            start_new_voyage = True

        if start_new_voyage:
            voyage_counter += 1
            current_voyage = f"V{voyage_counter:06d}"

        voyage_ids.append(current_voyage)
        prev_ship = ship
        prev_date = date
        prev_lat = lat
        prev_lon = lon

    df['voyage_id'] = voyage_ids

    if verbose:
        n_voyages = df['voyage_id'].nunique()
        print(f"\nResult: {n_voyages:,} voyages identified")

    return df

Creating Voyage Summaries

Once voyages are identified, we can create summary statistics for each one. These summaries capture the temporal extent (when did the voyage start and end?), spatial extent (where did it go?), and total distance traveled:

def create_voyage_summary(df):
    """
    Create summary statistics for each voyage.

    Returns DataFrame with one row per voyage containing:
    - Temporal extent (start/end dates, duration)
    - Spatial extent (bounding box, mean position)
    - Total distance traveled
    """
    summaries = []

    for vid in df['voyage_id'].unique():
        voyage = df[df['voyage_id'] == vid].sort_values('_datetime')

        summary = {
            'voyage_id': vid,
            'ship_id': voyage['ID'].iloc[0],
            'n_observations': len(voyage),
        }

        # Temporal
        summary['start_date'] = voyage['_datetime'].min()
        summary['end_date'] = voyage['_datetime'].max()
        summary['duration_days'] = (voyage['_datetime'].max() -
                                     voyage['_datetime'].min()).days

        # Spatial
        summary['start_lat'] = voyage['LAT'].iloc[0]
        summary['start_lon'] = voyage['LON'].iloc[0]
        summary['end_lat'] = voyage['LAT'].iloc[-1]
        summary['end_lon'] = voyage['LON'].iloc[-1]
        summary['mean_lat'] = voyage['LAT'].mean()
        summary['mean_lon'] = voyage['LON'].mean()

        # Total distance
        lats = voyage['LAT'].values
        lons = voyage['LON'].values
        total_dist = sum(haversine_km(lats[i-1], lons[i-1], lats[i], lons[i])
                        for i in range(1, len(lats)))
        summary['total_distance_km'] = total_dist

        summaries.append(summary)

    return pd.DataFrame(summaries)


# Create summaries for our demo
summary_df = create_voyage_summary(df_result)

print("=" * 60)
print(summary_df.to_string())

Spatial Profiles for Classification

For the next step (machine learning classification), we need to compute spatial profiles for each voyage. A spatial profile divides the world into a grid and records what proportion of a voyage’s observations fell into each cell:

def compute_spatial_profile(voyage_obs, lat_bins=5, lon_bins=5):
    """
    Compute spatial profile: proportion of observations in each grid cell.

    This captures WHERE a voyage spent its time, which differs between
    whaling ships (concentrated in whaling grounds) and merchants
    (following trade routes).
    """
    lat_edges = np.linspace(-90, 90, lat_bins + 1)
    lon_edges = np.linspace(-180, 180, lon_bins + 1)

    # Count observations in each cell
    hist, _, _ = np.histogram2d(
        voyage_obs['LAT'].values,
        voyage_obs['LON'].values,
        bins=[lat_edges, lon_edges]
    )

    # Normalize to proportions
    total = hist.sum()
    if total > 0:
        hist = hist / total

    return hist.flatten()


# Demo with one voyage
sample_voyage = df_result[df_result['voyage_id'] == 'V000001']
profile = compute_spatial_profile(sample_voyage)

print(f"Voyage V000001: {len(sample_voyage)} observations")
print(f"Profile: {len(profile)} cells (5×5 grid), sum = {profile.sum():.3f}")

The spatial profile is a fingerprint of where a voyage spent its time. A 5×5 grid divides the world’s oceans into 25 cells; the profile records what fraction of observations fell in each cell.

This matters for classification because whaling ships and merchant ships visit different parts of the ocean. Whalers concentrate in known whaling grounds (Pacific, Arctic, South Atlantic), while merchants follow trade routes between ports. The next notebook uses these profiles to train a classifier.

Key Takeaways

  1. Voyage reconstruction is non-trivial because of name collisions and gaps in the data.
  2. Schmidt’s four criteria provide a robust way to handle real-world data: same ship ID, temporal continuity (< 30 days), spatial continuity (< 1000 km), and no simultaneous distant observations.
  3. The haversine formula correctly calculates distances on a sphere, which is essential for geographic data.
  4. Name collisions can be detected when we find impossible simultaneous locations for the same ship ID.
  5. Spatial profiles summarize where a voyage spent its time, preparing the data for machine learning classification.

## The Challenge

Each ICOADS observation is independent—just a ship ID, position, and timestamp. To
reconstruct voyages, we need to connect observations from the same ship in sequence.
But there are complications:

**Problem 1: No Voyage IDs.** Each observation stands alone with no explicit link
to consecutive positions. We must infer voyages from patterns in the data.

**Problem 2: Multiple Voyages per Ship.** Ships made many voyages over years, so
the same ship ID appears hundreds of times. We need to separate these into distinct
journeys.

**Problem 3: Name Collisions (The Hard Part!).** Ship IDs are truncated to 9

five different vessels. When we see simultaneous observations at distant locations,
we know they must be different ships.

## Schmidt's Four-Criterion Algorithm

Ben Schmidt developed a robust algorithm that uses four criteria to decide whether
two consecutive observations belong to the same voyage:

1. **Same Ship Name.** The observations must have the same ID field. This groups
   observations by vessel identity.

2. **Temporal Continuity (< 30 days).** Consecutive observations must be within
   30 days of each other. Gaps longer than this indicate separate voyages by the
   same ship.

3. **Spatial Continuity (< 1000 km).** Consecutive observations must be within
   1000 km of each other. This prevents impossible jumps caused by data errors
   or long port stays.

4. **No Simultaneous Observations.** If the same ship ID appears in two distant
   locations on the same day, those observations must come from different physical
   ships. This criterion handles the name collision problem.

## Criterion 3: Spatial Continuity

To apply the spatial continuity criterion, we need to calculate distances between
consecutive observations. Since positions are on the surface of a sphere (the Earth),
we can't simply use the Pythagorean theorem. Instead, we use the **haversine formula**:

```{python}
def haversine_km(lat1, lon1, lat2, lon2):
    """
    Calculate great-circle distance between two points.

    The haversine formula accounts for Earth's curvature.
    Inputs are in decimal degrees; output is in kilometers.
    """
    R = 6371.0  # Earth's radius in kilometers

    # Convert to radians
    lat1_rad = np.radians(lat1)
    lat2_rad = np.radians(lat2)
    dlat = np.radians(lat2 - lat1)
    dlon = np.radians(lon2 - lon1)

    # Haversine formula
    a = np.sin(dlat / 2)**2 + np.cos(lat1_rad) * np.cos(lat2_rad) * np.sin(dlon / 2)**2
    c = 2 * np.arctan2(np.sqrt(a), np.sqrt(1 - a))

    return R * c

::: {.callout-note}
## Why Not Just Use Pythagorean Distance?
On a flat surface, distance = √((x₂-x₁)² + (y₂-y₁)²). But Earth is a sphere!
At the equator, 1° of longitude ≈ 111 km, but near the poles it approaches 0 km.
The haversine formula accounts for this curvature, giving accurate distances
regardless of latitude.
:::
```

## Criterion 4: Detecting Name Collisions

The trickiest part is handling **name collisions**—when different physical ships
share the same truncated ID. Schmidt's insight: if the same ID appears in two
distant locations on the same day, they must be different ships.

```{python}
def find_simultaneous_conflicts(df, distance_threshold=500):
    """
    Find days where the same ship ID appears at distant locations.

    This indicates multiple physical ships sharing a truncated name.
    Returns a set of (ID, date) tuples with conflicts.
    """
    conflicts = set()

    # Create date key for grouping
    df = df.copy()
    df['_date_key'] = df['Date'].dt.strftime('%Y-%m-%d')

    for (ship_id, date_key), group in df.groupby(['ID', '_date_key']):
        if len(group) < 2:
            continue

        # Check if any pair of observations is too far apart
        lats = group['LAT'].values
        lons = group['LON'].values

        for i in range(len(lats)):
            for j in range(i + 1, len(lats)):
                dist = haversine_km(lats[i], lons[i], lats[j], lons[j])
                if dist > distance_threshold:
                    conflicts.add((ship_id, date_key))
                    break

    return conflicts
```

## The Complete Algorithm

## Performance Note
The naive conflict detection below checks every pair of same-day observations—an O(n²)
operation. For 1.3 million records, this could be slow. The production script in

Putting it all together:

```{python}
def reconstruct_voyages(df, max_days=30, max_km=1000, verbose=True):
    """
    Reconstruct voyages using Schmidt's four-criterion algorithm.

    Parameters:
        df: DataFrame with YR, MO, DY, HR, LAT, LON, ID columns
        max_days: Maximum days between consecutive observations
        max_km: Maximum kilometers between consecutive observations
        verbose: Print progress information

    Returns:
        DataFrame with added 'voyage_id' column
    """
    if verbose:
        print(f"Input: {len(df):,} observations, {df['ID'].nunique():,} ship IDs")

    # Create datetime
    df = df.copy()
    df['_yr'] = pd.to_numeric(df['YR'], errors='coerce').fillna(1800).astype(int)
    df['_mo'] = pd.to_numeric(df['MO'], errors='coerce').fillna(1).astype(int).clip(1, 12)
    df['_dy'] = pd.to_numeric(df['DY'], errors='coerce').fillna(1).astype(int).clip(1, 28)

    date_str = (df['_yr'].astype(str) + '-' +
                df['_mo'].astype(str).str.zfill(2) + '-' +
                df['_dy'].astype(str).str.zfill(2))
    df['_datetime'] = pd.to_datetime(date_str, errors='coerce')
    df = df.dropna(subset=['_datetime', 'LAT', 'LON', 'ID'])

    # Sort by ship and time
    df = df.sort_values(['ID', '_datetime']).reset_index(drop=True)

    # Step 1: Find name collisions (criterion 4)
    if verbose:
        print("Detecting name collisions...")
    conflicts = find_simultaneous_conflicts(df)
    if verbose:
        print(f"  Found {len(conflicts)} conflict days")

    # Step 2: Assign voyage IDs
    if verbose:
        print("Assigning voyage IDs...")

    voyage_ids = []
    voyage_counter = 0
    current_voyage = None

    prev_ship = None
    prev_date = None
    prev_lat = None
    prev_lon = None

    for idx, row in df.iterrows():
        ship = row['ID']
        date = row['_datetime']
        lat = row['LAT']
        lon = row['LON']

        start_new_voyage = False

        # Check criterion 1: Same ship
        if ship != prev_ship:
            start_new_voyage = True
        elif prev_date is not None:
            # Check criterion 2: Time gap
            days_gap = (date - prev_date).days
            if days_gap > max_days:
                start_new_voyage = True
            else:
                # Check criterion 3: Distance
                dist = haversine_km(prev_lat, prev_lon, lat, lon)
                if dist > max_km:
                    start_new_voyage = True

        # Check criterion 4: Conflict day for this ship
        date_key = date.strftime('%Y-%m-%d')
        if (ship, date_key) in conflicts:
            # On conflict days, each observation starts a new voyage
            # (simplified handling)
            start_new_voyage = True

        if start_new_voyage:
            voyage_counter += 1
            current_voyage = f"V{voyage_counter:06d}"

        voyage_ids.append(current_voyage)
        prev_ship = ship
        prev_date = date
        prev_lat = lat
        prev_lon = lon

    df['voyage_id'] = voyage_ids

    if verbose:
        n_voyages = df['voyage_id'].nunique()
        print(f"\nResult: {n_voyages:,} voyages identified")

    return df


# Apply to our sample
```

## Creating Voyage Summaries

Once voyages are identified, we can create summary statistics for each one. These
summaries capture the temporal extent (when did the voyage start and end?), spatial
extent (where did it go?), and total distance traveled:

```{python}
def create_voyage_summary(df):
    """
    Create summary statistics for each voyage.

    Returns DataFrame with one row per voyage containing:
    - Temporal extent (start/end dates, duration)
    - Spatial extent (bounding box, mean position)
    - Total distance traveled
    """
    summaries = []

    for vid in df['voyage_id'].unique():
        voyage = df[df['voyage_id'] == vid].sort_values('_datetime')

        summary = {
            'voyage_id': vid,
            'ship_id': voyage['ID'].iloc[0],
            'n_observations': len(voyage),
        }

        # Temporal
        summary['start_date'] = voyage['_datetime'].min()
        summary['end_date'] = voyage['_datetime'].max()
        summary['duration_days'] = (voyage['_datetime'].max() -
                                     voyage['_datetime'].min()).days

        # Spatial
        summary['start_lat'] = voyage['LAT'].iloc[0]
        summary['start_lon'] = voyage['LON'].iloc[0]
        summary['end_lat'] = voyage['LAT'].iloc[-1]
        summary['end_lon'] = voyage['LON'].iloc[-1]
        summary['mean_lat'] = voyage['LAT'].mean()
        summary['mean_lon'] = voyage['LON'].mean()

        # Total distance
        lats = voyage['LAT'].values
        lons = voyage['LON'].values
        total_dist = sum(haversine_km(lats[i-1], lons[i-1], lats[i], lons[i])
                        for i in range(1, len(lats)))
        summary['total_distance_km'] = total_dist

        summaries.append(summary)

    return pd.DataFrame(summaries)
```

## Spatial Profiles for Classification

For the next step (machine learning classification), we need to compute **spatial
profiles** for each voyage. A spatial profile divides the world into a grid and
records what proportion of a voyage's observations fell into each cell:

```{python}
def compute_spatial_profile(voyage_obs, lat_bins=5, lon_bins=5):
    """
    Compute spatial profile: proportion of observations in each grid cell.

    This captures WHERE a voyage spent its time, which differs between
    whaling ships (concentrated in whaling grounds) and merchants
    (following trade routes).
    """
    lat_edges = np.linspace(-90, 90, lat_bins + 1)
    lon_edges = np.linspace(-180, 180, lon_bins + 1)

    # Count observations in each cell
    hist, _, _ = np.histogram2d(
        voyage_obs['LAT'].values,
        voyage_obs['LON'].values,
        bins=[lat_edges, lon_edges]
    )

    # Normalize to proportions
    total = hist.sum()
    if total > 0:
        hist = hist / total

    return hist.flatten()


# Demo with one voyage
sample_voyage = df_result[df_result['voyage_id'] == 'V000001']
profile = compute_spatial_profile(sample_voyage)

print(f"Voyage V000001: {len(sample_voyage)} observations")
print(f"Profile: {len(profile)} cells (5×5 grid), sum = {profile.sum():.3f}")
```

The spatial profile is a fingerprint of *where* a voyage spent its time. A 5×5 grid
divides the world's oceans into 25 cells; the profile records what fraction of
observations fell in each cell.

This matters for classification because whaling ships and merchant ships visit
different parts of the ocean. Whalers concentrate in known whaling grounds
(Pacific, Arctic, South Atlantic), while merchants follow trade routes between ports.
The next notebook uses these profiles to train a classifier.

## Key Takeaways

1. **Voyage reconstruction is non-trivial** because of name collisions and gaps in the data.
2. **Schmidt's four criteria** provide a robust way to handle real-world data: same ship ID,
   temporal continuity (< 30 days), spatial continuity (< 1000 km), and no simultaneous
   distant observations.
3. **The haversine formula** correctly calculates distances on a sphere, which is essential
   for geographic data.
4. **Name collisions** can be detected when we find impossible simultaneous locations for the
   same ship ID.
5. **Spatial profiles** summarize where a voyage spent its time, preparing the data for
   machine learning classification.

2. We use a 500 km threshold to detect name collisions (simultaneous observations

3. The name collision detection treats each observation on a conflict day as a
   separate voyage. Can you think of a more sophisticated approach that might
   correctly group observations from the *same* physical ship on a conflict day?

4. Spatial profiles divide the ocean into a grid. What are the tradeoffs between
   using a coarse grid (5×5) versus a fine grid (50×50)?

5. This algorithm reconstructs voyages from fragmentary evidence—ship IDs, positions,
   and timestamps. Historians often face similar challenges when working with incomplete
   records. What other kinds of historical data might benefit from algorithmic
   "reconstruction"? (Think about letters, financial records, migration patterns, etc.)

6. The name collision problem arises because the original record-keepers truncated
   ship names to save space on punch cards. What does this tell us about how the
   constraints of one era's technology can create challenges for future researchers?
   Can you think of analogous issues with how we store data today?

7. We're treating all voyages the same, but a whaling voyage might last 2-3 years

   to handle such different voyage types? Should you use different thresholds for
   different kinds of ships?
