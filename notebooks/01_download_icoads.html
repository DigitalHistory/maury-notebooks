Step 1: Downloading Historical Ship Logbook Data from ICOADS

Downloading Historical Ship Logbook Data from ICOADS

This notebook explains how to download Matthew Maury’s historic ship logbook collection from the ICOADS (International Comprehensive Ocean-Atmosphere Data Set) archive. By the end, you’ll understand:

  1. What ICOADS is and why it matters for historical research
  2. What a “deck” is and why we want deck 701
  3. How the download script works step by step
  4. The IMMA1 fixed-width format used to store the data

Note: The full download takes several hours and downloads ~500MB. This notebook explains the process; you can run the script separately or use pre-built data files.

Who Was Matthew Maury?

Matthew Fontaine Maury (1806-1873) was a US Navy officer who revolutionized maritime navigation and founded modern oceanography. After an injury ended his sea career, he became Superintendent of the US Naval Observatory where he had a brilliant insight: systematically collect and analyze ship logbooks.

Maury convinced ship captains worldwide to record standardized observations of wind, weather, currents, and sea conditions. By synthesizing thousands of logbooks, he created the first wind and current charts that dramatically reduced sailing times—sometimes by weeks!

His 1855 book “The Physical Geography of the Sea” is widely considered the first textbook of modern oceanography.

What is ICOADS?

ICOADS (International Comprehensive Ocean-Atmosphere Data Set) is the world’s largest collection of historical ocean-atmosphere observations. Maintained by NOAA’s National Centers for Environmental Information (NCEI), it contains hundreds of millions of marine observations dating back to the 1600s.

The data is organized by deck number—a historical term from the punch card era. Each deck represents a distinct data collection:

Deck Description
701 US Maury Collection (our focus!)
702 US Marine Meteorological Journals
704 US Merchant Marine Collection
720 UK Met Office Main Marine Data Bank

Deck 701 contains Maury’s original digitized logbook collection from 1795-1861.

The Download Process

Let’s walk through the download script (scripts/download_icoads_deck701.py) to understand how it works.

Step 1: Understanding the Archive Structure

ICOADS data is organized by year and month. Each file is gzip-compressed and made available at a URL of the form https://www.ncei.noaa.gov/data/international-comprehensive-ocean-atmosphere/v3/archive/final-untrim/IMMA1_R3.1.-_{TEAR}-{MONTH}.jz

Step 3: Finding the Deck Number

The deck number is in the C1 attachment, which follows the core section. For ICOADS R3.1, the deck number is at positions 118-120:

def get_deck_number(line):
    """
    Extract the deck number (DCK) from an IMMA1 record.

    The deck number identifies which collection the record belongs to.
    Deck 701 = US Maury Collection
    """
    DCK_START = 118
    DCK_END = 121

    if len(line) < DCK_END:
        return None

    dck = line[DCK_START:DCK_END]

    # Verify it's a valid deck number (3 digits)
    if dck.isdigit():
        return dck

    return None

Step 4: The Filter Logic

For each monthly file, we download, decompress, and filter:

import gzip
import io

def demonstrate_filtering(lines):
    """
    Show how we filter IMMA1 records for deck 701.
    """
    deck701_count = 0
    other_decks = {}

    for line in lines:
        deck = get_deck_number(line)
        if deck == '701':
            deck701_count += 1
        elif deck:
            other_decks[deck] = other_decks.get(deck, 0) + 1

    return deck701_count, other_decks

Step 5: The Main Download Loop

Here’s the core logic from scripts/download_icoads_deck701.py:

# Simplified version of the download function (don't run - just for illustration)
DOWNLOAD_CODE = '''
import gzip
import urllib.request

def download_and_filter_deck701(start_year=1795, end_year=1861, output_file='data/icoads_deck701_maury.imma'):
    """Download ICOADS IMMA1 files and filter for deck 701 records."""

    base_url = "https://www.ncei.noaa.gov/data/international-comprehensive-ocean-atmosphere/v3/archive/final-untrim/"

    with open(output_file, 'w') as outf:
        for year in range(start_year, end_year + 1):
            for month in range(1, 13):
                filename = f"IMMA1_R3.1.0_{year}-{month:02d}.gz"
                url = base_url + filename

                try:
                    # Download compressed file
                    with urllib.request.urlopen(url, timeout=60) as response:
                        compressed_data = response.read()

                    # Decompress and process
                    data = gzip.decompress(compressed_data).decode('utf-8', errors='replace')

                    for line in data.strip().split('\\n'):
                        # Check if this record is from deck 701
                        if len(line) > 120 and line[118:121] == '701':
                            outf.write(line + '\\n')

                except urllib.error.HTTPError as e:
                    if e.code == 404:
                        print(f"No data for {year}-{month:02d}")
                    else:
                        raise
'''

Running the Download

To actually download the data, it is certainly possible to use the associated notebook. But it is easier to run the full script in teh background. From the project root:

uv run python scripts/download_icoads_deck701.py

Options:

  • --start-year 1840 --end-year 1850: Download only a subset of years
  • -o custom_output.imma: Specify output file
  • -q: Quiet mode (suppress progress)

Expected output: - Time: Fifteen minutes to several hours (depends on network speed) - File: data/icoads_deck701_maury.imma (~567 MB) - Records: ~1.3 million Maury collection observations

```{python}
- Total records in file: ~50,000
- Deck 701 (Maury) records: ~2,000 (4%)
  - Other decks: ~48,000 (96%)
""")
```

### Step 5: The Main Download Loop

Here's the core logic from `scripts/download_icoads_deck701.py`:

```{python}
# Simplified version of the download function (don't run - just for illustration)
DOWNLOAD_CODE = '''
import gzip
import urllib.request

def download_and_filter_deck701(start_year=1795, end_year=1861, output_file='data/icoads_deck701_maury.imma'):
    """Download ICOADS IMMA1 files and filter for deck 701 records."""

    base_url = "https://www.ncei.noaa.gov/data/international-comprehensive-ocean-atmosphere/v3/archive/final-untrim/"

    with open(output_file, 'w') as outf:
        for year in range(start_year, end_year + 1):
            for month in range(1, 13):
                filename = f"IMMA1_R3.1.0_{year}-{month:02d}.gz"
                url = base_url + filename

                try:
                    # Download compressed file
                    with urllib.request.urlopen(url, timeout=60) as response:
                        compressed_data = response.read()

                    # Decompress and process
                    data = gzip.decompress(compressed_data).decode('utf-8', errors='replace')

                    for line in data.strip().split('\\n'):
                        # Check if this record is from deck 701
                        if len(line) > 120 and line[118:121] == '701':
                            outf.write(line + '\\n')

                except urllib.error.HTTPError as e:
                    if e.code == 404:
                        print(f"No data for {year}-{month:02d}")
                    else:
                        raise
'''
```
