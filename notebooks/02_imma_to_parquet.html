Step 2: Converting IMMA1 to Parquet Format

Converting IMMA1 to Parquet Format

This notebook explains how to convert the downloaded IMMA1 data to Apache Parquet, a modern columnar format optimized for analytical queries. You’ll learn:

  1. Why fixed-width formats exist and their historical context
  2. How to parse IMMA1 fields including coordinate encoding
  3. What columnar storage means and why it matters
  4. How Parquet achieves 37× compression on our data

Why Convert Formats?

The IMMA1 (International Maritime Meteorological Archive) format dates from the era of punch cards and magnetic tape. While it has served well for archival purposes, modern analysis benefits from formats designed for today’s tools.

IMMA1: A Fixed-Width Text Format

In fixed-width formats, each field occupies specific character positions in every line:

# A sample IMMA1 record
sample = "1840 1 1     3702 28605 13 4    10LOUISVIL   1"

print("Fixed-Width Format Example:")
print("=" * 60)
print(f"Record: '{sample[:50]}...'")
print()
print("Position | Value | Meaning")
print("-" * 40)
print(f"  0-4    | '{sample[0:4]}'  | Year")
print(f"  4-6    | '{sample[4:6]}'  | Month")
print(f"  6-8    | '{sample[6:8]}'  | Day")
print(f" 12-17   | '{sample[12:17]}' | Latitude (×100)")
print(f" 17-23   | '{sample[17:23]}'| Longitude (×100)")
print(f" 35-44   | '{sample[35:44]}'| Ship ID")

----------------------------------------
  0-4    | '1840'  | Year
  4-6    | ' 1'  | Month

Advantages in the punch card era: - No delimiters needed (saves space) - Easy to read specific columns from tape - Self-documenting if you know the schema

Disadvantages for modern analysis: - Must read entire records even if you need one field - Everything is text (no native numbers) - No compression - Requires custom parsers

CSV: A Standard Replacement

We can convert fixed-width data to CSV (Comma-Separated Values), a more widely-supported format.

Here are our three sample IMMA1 records:

1840 1 1     3702 28605 13 4    10LOUISVIL
1840 1 2     3810 28720 13 4    10LOUISVIL
1840 1 3     3650 28410 13 4    10LOUISVIL

After parsing the fixed positions and converting coordinates (divide by 100, subtract 360 for west longitudes), we get this table:

year month day lat lon ship_id
1840 1 1 37.02 -73.95 LOUISVIL
1840 1 2 38.10 -72.80 LOUISVIL
1840 1 3 36.50 -75.90 LOUISVIL

The equivalent CSV representation:

year,month,day,lat,lon,ship_id
1840,1,1,37.02,-73.95,LOUISVIL
1840,1,2,38.10,-72.80,LOUISVIL
1840,1,3,36.50,-75.90,LOUISVIL

CSV is a row-based storage format—each line contains all fields for one observation, separated by commas. While CSV is more portable than fixed-width:

  • Pro: Human-readable delimiters, widely supported by all tools
  • Pro: Self-describing headers
  • Con: Still stores data row-by-row (inefficient for column operations)
  • Con: No native types (everything is text)
  • Con: Poor compression (similar values scattered across rows)

For analytical workloads, we need something better: columnar storage.

Parquet: A Modern Columnar Format

Apache Parquet stores data by column rather than by row:

Row-based (IMMA1, CSV):
  Record 1: 1840, 1, 1, 37.02, -73.95, LOUISVIL, ...
  Record 2: 1840, 1, 2, 38.10, -72.80, LOUISVIL, ...
  Record 3: 1840, 1, 3, 36.50, -74.10, LOUISVIL, ...

Columnar (Parquet):
  Year column:  [1840, 1840, 1840, ...]
  Month column: [1, 1, 1, ...]
  Day column:   [1, 2, 3, ...]
  Lat column:   [37.02, 38.10, 36.50, ...]
  Lon column:   [-73.95, -72.80, -74.10, ...]
  Ship column:  [LOUISVIL, LOUISVIL, LOUISVIL, ...]

Why columnar is better for analysis:

  1. Similar values together → excellent compression
  2. Read only needed columns → faster queries
  3. Type-specific encoding → efficient storage
  4. Vectorized operations → CPU optimization

Parsing IMMA1 Records

Let’s walk through the parsing logic in scripts/imma_to_parquet.py.

Core Fields

MO 4-6 2 Month

Coordinate Encoding

Latitude and longitude use a special encoding that requires careful parsing. We’ll write a python conversion to convert to familiar units:

def parse_lat(raw_value):
    """
    Parse IMMA1 latitude field.

    Format: Signed integer, scaled by 100.
    Example: 3702 → 37.02°N, -2190 → 21.90°S
    """
    if not raw_value or not raw_value.strip():
        return None
    try:
        raw = int(raw_value)
        return raw / 100.0  # Divide by 100 to get decimal degrees
    except ValueError:
        return None


def parse_lon(raw_value):
    """
    Parse IMMA1 longitude field.

    Format: Integer scaled by 100, with special encoding for west.
    - Values 0-18000: 0° to 180°E
    - Values > 18000: West longitudes stored as (360 + lon) × 100

    Example: 28605 → 286.05 → 286.05 - 360 = -73.95°W
    """
    if not raw_value or not raw_value.strip():
        return None
    try:
        raw = int(raw_value)
        lon = raw / 100.0
        if lon > 180:
            lon = lon - 360  # Convert to negative (west) longitude
        return lon
    except ValueError:
        return None

Temperature and Pressure Fields

Meteorological fields also need a conversion function:

def parse_scaled_field(value, scale=10):
    """
    Parse a scaled numeric field.

    Many IMMA1 fields store values multiplied by 10 to avoid decimals.
    Example: Temperature 235 → 23.5°C
    """
    if not value or not value.strip():
        return None
    try:
        return int(value) / scale
    except ValueError:
        return None
Field Raw Value Scale Result
SLP (hPa) 10132 10 1013.2 hPa
AT (°C) 235 10 23.5°C
SST (°C) 182 10 18.2°C
HR (time) 1430 100 14.30 (2:30 PM)

The Complete Parser

Here’s the full record parsing function. It’s long because each field needs to be handled explicitly:

def parse_imma1_line(line):
    """
    Parse a single IMMA1 record into a dictionary.

    Returns a dict with all extracted fields, properly typed.
    """
    record = {}

    # Date/time fields
    record['YR'] = line[0:4].strip() or None
    record['MO'] = line[4:6].strip() or None
    record['DY'] = line[6:8].strip() or None

    # Hour (stored as HHMM, convert to decimal hours)
    hr_raw = line[8:12].strip()
    if hr_raw:
        try:
            record['HR'] = int(hr_raw) / 100.0
        except ValueError:
            record['HR'] = None
    else:
        record['HR'] = None

    # Position with correct parsing
    record['LAT'] = parse_lat(line[12:17])
    record['LON'] = parse_lon(line[17:23])

    # Ship identification
    record['ID'] = line[35:44].strip() or None

    # Sea level pressure (tenths of hPa)
    slp_raw = line[62:67].strip()
    record['SLP'] = parse_scaled_field(slp_raw) if slp_raw else None

    # Air temperature (tenths of °C)
    at_raw = line[72:76].strip()
    record['AT'] = parse_scaled_field(at_raw) if at_raw else None

    # Sea surface temperature (tenths of °C)
    sst_raw = line[87:91].strip()
    record['SST'] = parse_scaled_field(sst_raw) if sst_raw else None

    # Deck number from C1 attachment
    if len(line) > 124:
        record['DCK'] = line[118:121].strip() or None
    else:
        record['DCK'] = None

    return record

Selective Column Reading

One of Parquet’s key advantages is reading only the columns you need:

# Load everything
df_full = pd.read_parquet('data/icoads_deck701_maury.parquet')

# Load only positions
df_positions = pd.read_parquet(
    'data/icoads_deck701_maury.parquet',
    columns=['YR', 'LAT', 'LON']

# → Loads 3 columns, uses ~30MB memory, 5× faster

# Load with filtering (requires pyarrow filters)
import pyarrow.parquet as pq
table = pq.read_table(
    'data/icoads_deck701_maury.parquet',
    columns=['LAT', 'LON', 'SST'],
    filters=[('YR', '>=', '1840'), ('YR', '<', '1850')]
)
# → Only reads 1840s data from disk

Running the Full Conversion

Now let’s convert the complete ICOADS dataset. The full file has ~1.3 million records, so we’ll process it in chunks to avoid running out of memory.

Memory Management with Chunks

When processing large files, we can’t load everything into memory at once. Instead, we:

  1. Read a “chunk” of records (e.g., 100,000 at a time)
  2. Convert that chunk to Parquet format
  3. Append it to the output file
  4. Repeat until done

PyArrow’s ParquetWriter handles the appending automatically.

Step 1: Set Up the Conversion

First, let’s define our input/output paths and verify the input file exists:

from pathlib import Path
import pyarrow as pa
import pyarrow.parquet as pq

# File paths
input_file = Path('data/icoads_deck701_maury.imma')
output_file = Path('data/icoads_deck701_maury.parquet')

# Verify input exists
if input_file.exists():
    input_size_mb = input_file.stat().st_size / 1024 / 1024
    print(f"Input file: {input_file}")
    print(f"Size: {input_size_mb:.1f} MB")
else:
    print(f"Input file not found: {input_file}")
    print("Run the download script first: uv run python scripts/download_icoads_deck701.py")

Step 2: Count Records (Optional)

Counting records first lets us show progress. This takes a few seconds on a large file:

# Count lines for progress reporting
total_records = sum(1 for _ in open(input_file))
print(f"Total records: {total_records:,}")

Step 3: Process in Chunks

Here’s the core conversion loop. We read the file line by line, parse each record, and write to Parquet in batches:

chunk_size = 100_000  # Records per chunk
records = []
records_processed = 0
writer = None

with open(input_file, 'r', encoding='utf-8', errors='replace') as f:
    for line in f:
        line = line.rstrip('\n\r')
        if not line:
            continue

        # Parse the IMMA1 record (using our function from earlier)
        record = parse_imma1_line(line)
        records.append(record)
        records_processed += 1

        # When chunk is full, write to Parquet
        if len(records) >= chunk_size:
            df_chunk = pd.DataFrame(records)
            table = pa.Table.from_pandas(df_chunk)

            # Create writer on first chunk (to capture schema)
            if writer is None:
                writer = pq.ParquetWriter(output_file, table.schema, compression='snappy')

            writer.write_table(table)
            records = []  # Clear for next chunk

            print(f"Processed {records_processed:,} records...")

# Don't forget the final partial chunk!
if records:
    df_chunk = pd.DataFrame(records)
    table = pa.Table.from_pandas(df_chunk)
    if writer is None:
        writer = pq.ParquetWriter(output_file, table.schema, compression='snappy')
    writer.write_table(table)

# Close the writer
if writer:
    writer.close()

print(f"\nConversion complete: {records_processed:,} records")
Don’t Forget the Final Chunk!

A common bug is forgetting to write the last partial chunk after the loop ends. If your file has 1,350,000 records and your chunk size is 100,000, the last 50,000 records would be lost without the final if records: block.

Step 4: Verify the Output

# Check output file
output_size_mb = output_file.stat().st_size / 1024 / 1024
compression_ratio = input_size_mb / output_size_mb

print(f"Output file: {output_file}")

print(f"Compression ratio: {compression_ratio:.1f}x")

Apache Parquet stores data **by column** rather than by row:

``` text

  Month column: [1, 1, 1, ...]
  Day column:   [1, 2, 3, ...]
  Lat column:   [37.02, 38.10, 36.50, ...]
  Lon column:   [-73.95, -72.80, -74.10, ...]
  Ship column:  [LOUISVIL, LOUISVIL, LOUISVIL, ...]
```

**Why columnar is better for analysis:**

1. Similar values together → excellent compression
2. Read only needed columns → faster queries
3. Type-specific encoding → efficient storage
4. Vectorized operations → CPU optimization

## Parsing IMMA1 Records

Let's walk through the parsing logic in `scripts/imma_to_parquet.py`.

### Core Fields

The IMMA1 core section occupies positions 0-107 (108 characters):

| Field | Positions | Width | Description |
|-------|-----------|-------|-------------|
| YR    | 0-4       | 4     | Year |
| MO    | 4-6       | 2     | Month |
| DY    | 6-8       | 2     | Day |
| HR    | 8-12      | 4     | Hour (HHMM format) |
| LAT   | 12-17     | 5     | Latitude (special encoding) |
| LON   | 17-23     | 6     | Longitude (special encoding) |
| ID    | 35-44     | 9     | Ship identifier |
| SLP   | 62-67     | 5     | Sea level pressure |
| AT    | 72-76     | 4     | Air temperature |
| SST   | 87-91     | 4     | Sea surface temperature |

### Coordinate Encoding

Latitude and longitude use a special encoding that requires careful parsing. We'll write a python conversion to convert to familiar units:

```{python}
def parse_lat(raw_value):
    """
    Parse IMMA1 latitude field.

    Format: Signed integer, scaled by 100.
    Example: 3702 → 37.02°N, -2190 → 21.90°S
    """
    if not raw_value or not raw_value.strip():
        return None
    try:
        raw = int(raw_value)
        return raw / 100.0  # Divide by 100 to get decimal degrees
    except ValueError:
        return None


def parse_lon(raw_value):
    """
    Parse IMMA1 longitude field.

    Format: Integer scaled by 100, with special encoding for west.
    - Values 0-18000: 0° to 180°E
    - Values > 18000: West longitudes stored as (360 + lon) × 100

    Example: 28605 → 286.05 → 286.05 - 360 = -73.95°W
    """
    if not raw_value or not raw_value.strip():
        return None
    try:
        raw = int(raw_value)
        lon = raw / 100.0
        if lon > 180:
            lon = lon - 360  # Convert to negative (west) longitude
        return lon
    except ValueError:
        return None


# Demonstrate coordinate parsing
print("Coordinate Parsing Examples:")
print("=" * 60)

test_cases = [
    ("3702", "28605", "New York area"),
    ("2085", "30440", "Caribbean"),
    ("-2190", "5377", "South Atlantic"),
    ("4520", "12350", "Mediterranean"),
]

for lat_raw, lon_raw, description in test_cases:
    lat = parse_lat(lat_raw)
    lon = parse_lon(lon_raw)
    print(f"\n{description}:")
    print(f"  Raw:     LAT='{lat_raw}', LON='{lon_raw}'")
    print(f"  Decoded: {lat:.2f}°, {lon:.2f}°")
```

### Temperature and Pressure Fields

Meteorological fields also need a conversion function:

```{python}
def parse_scaled_field(value, scale=10):
    """
    Parse a scaled numeric field.

    Many IMMA1 fields store values multiplied by 10 to avoid decimals.
    Example: Temperature 235 → 23.5°C
    """
    if not value or not value.strip():
        return None
    try:
        return int(value) / scale
    except ValueError:
        return None
```

| Field     | Raw Value | Scale | Result |
|-----------|-----------|-------|--------|
| SLP (hPa) | 10132     | 10    | 1013.2 hPa |
| AT (°C)   | 235       | 10    | 23.5°C |
| SST (°C)  | 182       | 10    | 18.2°C |
| HR (time) | 1430      | 100   | 14.30 (2:30 PM) |

### The Complete Parser

Here's the full record parsing function. It's long because each field needs to be handled explicitly:

```{python}
def parse_imma1_line(line):
    """
    Parse a single IMMA1 record into a dictionary.

    Returns a dict with all extracted fields, properly typed.
    """
    record = {}

    # Date/time fields
    record['YR'] = line[0:4].strip() or None
    record['MO'] = line[4:6].strip() or None
    record['DY'] = line[6:8].strip() or None

    # Hour (stored as HHMM, convert to decimal hours)
    hr_raw = line[8:12].strip()
    if hr_raw:
        try:
            record['HR'] = int(hr_raw) / 100.0
        except ValueError:
            record['HR'] = None
    else:
        record['HR'] = None

    # Position with correct parsing
    record['LAT'] = parse_lat(line[12:17])
    record['LON'] = parse_lon(line[17:23])

    # Ship identification
    record['ID'] = line[35:44].strip() or None

    # Sea level pressure (tenths of hPa)
    slp_raw = line[62:67].strip()
    record['SLP'] = parse_scaled_field(slp_raw) if slp_raw else None

    # Air temperature (tenths of °C)
    at_raw = line[72:76].strip()
    record['AT'] = parse_scaled_field(at_raw) if at_raw else None

    # Sea surface temperature (tenths of °C)
    sst_raw = line[87:91].strip()
    record['SST'] = parse_scaled_field(sst_raw) if sst_raw else None

    # Deck number from C1 attachment
    if len(line) > 124:
        record['DCK'] = line[118:121].strip() or None
    else:
        record['DCK'] = None

    return record


# Demonstrate parsing

print("=" * 60)

    if value is not None:
        print(f"  {key:6}: {value}")
```

## Running the Full Conversion

Now let's convert the complete ICOADS dataset. The full file has ~1.3 million records, so we'll
process it in chunks to avoid running out of memory.

::: {.callout-tip}
## Memory Management with Chunks
When processing large files, we can't load everything into memory at once. Instead, we:

1. Read a "chunk" of records (e.g., 100,000 at a time)
2. Convert that chunk to Parquet format
3. Append it to the output file
4. Repeat until done

PyArrow's `ParquetWriter` handles the appending automatically.
:::

### Step 1: Set Up the Conversion

First, let's define our input/output paths and verify the input file exists:

```{python}

# Verify input exists
```

### Step 3: Process in Chunks

Here's the core conversion loop. We read the file line by line, parse each record,
and write to Parquet in batches:

```{python}
#| eval: false

chunk_size = 100_000  # Records per chunk
records = []
records_processed = 0
writer = None

with open(input_file, 'r', encoding='utf-8', errors='replace') as f:
    for line in f:
        line = line.rstrip('\n\r')
        if not line:
            continue

        # Parse the IMMA1 record (using our function from earlier)
        record = parse_imma1_line(line)
        records.append(record)
        records_processed += 1

        # When chunk is full, write to Parquet
        if len(records) >= chunk_size:
            df_chunk = pd.DataFrame(records)
            table = pa.Table.from_pandas(df_chunk)

            # Create writer on first chunk (to capture schema)
            if writer is None:
                writer = pq.ParquetWriter(output_file, table.schema, compression='snappy')

            writer.write_table(table)
            records = []  # Clear for next chunk

            print(f"Processed {records_processed:,} records...")

# Don't forget the final partial chunk!
if records:
    df_chunk = pd.DataFrame(records)
    table = pa.Table.from_pandas(df_chunk)
    if writer is None:
        writer = pq.ParquetWriter(output_file, table.schema, compression='snappy')
    writer.write_table(table)

# Close the writer
if writer:
    writer.close()

print(f"\nConversion complete: {records_processed:,} records")
```

::: {.callout-warning}
## Don't Forget the Final Chunk!
A common bug is forgetting to write the last partial chunk after the loop ends.
If your file has 1,350,000 records and your chunk size is 100,000, the last 50,000
records would be lost without the final `if records:` block.
:::
